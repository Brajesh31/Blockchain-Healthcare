# 🆘 Support

## Before reporting a problem

1. Identify the affected file or workflow.
2. Check the [installation guide](docs/installation.md) and [troubleshooting guide](docs/troubleshooting.md).
3. Confirm Node.js/npm, browser wallet, chain ID, contract address, compiler version, and ABI.
4. Reproduce with a local chain or testnet and synthetic data only.
5. Remove sensitive data from logs and screenshots.

## Include in a support request

- OS and browser.
- Node.js and npm versions.
- Wallet type and test chain ID.
- Contract address only when safe to share.
- Exact steps and expected/actual behavior.
- Sanitized error text and transaction reference where appropriate.

## Never include

Patient names, diagnoses, treatments, medical identifiers, private keys, seed phrases, wallet backups, cookies, or credentials.

This is an educational repository. It does not offer a production service SLA or clinical support.
